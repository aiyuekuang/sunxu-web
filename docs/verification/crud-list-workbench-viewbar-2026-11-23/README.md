# CRUD 列表视图栏位置验收

## 范围

- 路由：`/customers`（Tel 管理端本地 CRM 界面验收页）
- 数据：脚本内存模拟数据；不连接业务后端、不发起业务写入
- 视口：桌面 `1470 × 745`；窄工作区 `860 × 900`
- 状态：个人客户分类已选中；管理视图已加载，含默认视图和个人视图
- 截图：本次任务的浏览器验收输出保留了两个视口的实际页面截图

## 几何与溢出

| 区域 | 桌面位置与尺寸 | 窄视口位置与尺寸 |

- 分类行到视图栏、视图栏到搜索/操作行均为 `8px`。
- 搜索/操作行到结果表格为 `16px`。
- 桌面与窄视口的 document/workbench 水平溢出均为 `0px`。
- 窄视口下视图管理按钮换行，搜索/操作区纵向排列；控件仍完整可见。

## 结论

视图栏位于客户分类行之后、搜索/操作行之前，与列表结果保持同一工作区层级；窄工作区无水平溢出。

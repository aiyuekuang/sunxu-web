# SavedViewBar 宽窄工作区验收

## 场景

- 页面：`examples/catalog` → `CRUD 列表工作台` → `复杂视图`。
- 数据：目录示例的 8 个合成产品视图；不连接业务后端。
- 浏览器实际渲染 Sunxu Web 构建产物，使用同一个真实组件路由检查两个视口。

## 几何与溢出

| 视口 | 视图栏容器 | 视图标签 | 操作区 | 页面横向滚动 | 结果 |
|---|---:|---|---|---:|---|
| 1440 × 900 | x=309, y=444, w=1046, h=58 | x=309, y=444, w=900, h=56 | x=1225, y=456, w=130, h=32 | `scrollWidth=1440`，与视口相同 | 标签与按钮处于同一行 |
| 1024 × 768 | x=281, y=494, w=670, h=98 | x=281, y=494, w=670, h=56 | x=281, y=558, w=670, h=32 | `scrollWidth=1024`，与视口相同 | 工作区窄于 900px，操作区在下方；标签保持单行 |

截图在对应的 Codex 浏览器验收记录中捕获。桌面断点下 8 个视图和操作区同时可见；窄工作区按组件契约把操作区放到标签下方，页面未产生横向溢出。

## 结论

修复前 `.sxw-saved-view-bar__row` 默认使用纵向布局，且操作区宽度强制为 100%，所以宽屏也固定出现两行。现在宽工作区用两列网格布局：标签列按剩余空间收缩，操作区保留固有宽度。窄工作区沿用工作台的 900px 容器断点，操作区才移到第二行。

# SavedViewBar 标签和操作区对齐验收

## 场景

- 页面：`examples/catalog` → `CRUD 列表工作台` → `复杂视图`。
- 数据：目录示例的 8 个合成产品视图；不连接业务后端。
- 当前问题：Tabs 自带的导航伪元素只覆盖左侧标签列；同一行的排序/保存操作按整个 Tabs 外框居中，按钮下边与标签分隔线错开。
- 修复目标：标签和操作成为一个视觉组合，共享全宽分隔线；宽屏按钮底边与分隔线重合；窄容器仍由组件契约将操作移到标签下方。

## 修复前测量

| 视口 | 状态 | 视图栏 / Tabs 导航 / 按钮位置 | 结果 |
|---|---|---|---|
| 1440 × 900 | 复杂视图，8 个标签，系统视图选中 | 视图栏 `y=444.42..502.42`；Tabs 头 `y=444.42..484.42`；按钮 `y=456.42..488.42` | 按钮底边比 Tabs 分隔线低 4px；Tabs 自带分隔线只覆盖标签列 |
| 1024 × 768 | 复杂视图，8 个标签，系统视图选中 | 工作区宽 670px；操作区在标签下方；页面 `scrollWidth=1024` | 窄工作区换行是预期行为，无横向溢出 |
